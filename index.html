个人经历

我是一名拥有 12 年开发经验的全栈工程师，深耕 Java 后端与 React / Vue.js 前端，同时涉猎 Python 量化与开发者工具领域。从企业级应用到独立开发，从架构设计到代码落地，我享受用技术解决实际问题的过程。

工作之余，我热衷于开源社区贡献、技术博客写作与独立工具开发。我相信优秀的代码应该简洁、高效、可维护。在这里，你可以看到我的项目成果、技术沉淀与持续学习的路径。
